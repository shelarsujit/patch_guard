# Submission video

`patch-guard.mp4` — 1920x1080, under the five-minute limit.

It was generated, not recorded: slides drawn from the figures in
`results/report.md`, narration synthesized, ffmpeg assembly. Nothing in it was
edited by hand, which is the point — the video is downstream of the
measurements, so a number cannot drift between the evidence and the
presentation without a rebuild.

The generator is not part of Patch-Guard and is not shipped here. It lives in
git history at `c4eb498` (`video/build_video.py`, `video/sections.py`).
